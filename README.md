## What I am building

I am a Technical Support Specialist growing into Cloud, Security, and AI Engineering. My work explores how humans and AI agents can collaborate safely in real products, not only generate answers.

My current focus is SparkKit, an open-source foundation for software built with AI coding agents and designed for humans and agents to work together. My interests include agent authorization, approval-driven automation, application contracts, verification systems, tenant-safe software architecture, and auditable AI workflows.

```text
tickets.read       ALLOW
knowledge.search   ALLOW
drafts.create      ALLOW
refund.execute     APPROVAL
customers.delete   DENY
```

The goal is simple: make powerful AI useful inside real workflows while keeping people in control.

## Featured work

### [SparkKit](https://github.com/ousssamarahmani/SparkKit-Core-V1)

An open-source foundation for building portable software and multiplayer AI applications. It combines a modern application stack with tenant isolation, authentication, organizations, and a path toward policy-controlled agent actions.

`TypeScript` · `Next.js` · `PostgreSQL` · `Prisma` · `Docker`

### [GroundPulse AI Research Datasets](https://github.com/ousssamarahmani/GroundPulse-AI-Research-Datasets)

A source-backed research data foundation for satellite and ground-segment intelligence, designed around traceable evidence and explicit knowledge gaps.

`TypeScript` · `Research Data` · `Evidence Provenance`

### [GroundPulse Research Agent](https://github.com/ousssamarahmani/Groundpulse-Research-Agent)

A bounded research agent that validates what sources can support, preserves uncertainty, and avoids inventing missing answers.

`AI Agents` · `Source Validation` · `Responsible AI`

### [EntraX](https://github.com/ousssamarahmani/EntraX)

An identity-visualization concept for Microsoft Entra ID that maps access paths and uses agentic AI to explain issues, detect patterns, and recommend next steps.

`Identity Security` · `Microsoft Entra ID` · `Agentic AI`
